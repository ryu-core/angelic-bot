## AntiNuke

AntiNuke watches destructive audit-log actions and evaluates them against module thresholds. Configure modules independently, select a punishment, provide a log channel, and whitelist automation that should bypass enforcement.

<section id="access">

## Access & whitelist

Admins can manage protection settings. Whitelisted IDs bypass AntiNuke enforcement. Trusted IDs are intended for users allowed to add or operate approved bots. Every ID is validated as a Discord snowflake before it is saved.

</section>

<section id="consoles">

## Owner & co-owner consoles

Access is checked on the server against <code>OWNER_IDS</code> and <code>CO_OWNER_IDS</code>. Co-owners may manage premium and profile grants. Only owners can create global bans or make the bot leave a server.
